# 0085. 최소 운영 자금 기준의 현금흐름 경고

상태: 제안

잔액이 양수여도 가맹점이 운영에 필요한 자금을 확보하지 못할 수 있다. 가맹점별로 경고 기준을 설정하고 모든 조회 기간에 같은 기준을 적용한다.

기존 `cash_flow_settings`에 `minimum_operating_funds`를 원 단위로 저장한다. 기존 행의 기본값은 0원이다. 설정 API에서 이 금액을 처음 입력하거나 수정할 수 있다. 최초 시작 잔액과 기준일의 변경 금지 규칙을 유지한다.

예측의 일별 마감 잔액 계산은 유지한다. 마감 잔액이 최소 운영 자금보다 낮은 날을 부족일로 보고, 두 금액의 차이를 부족액으로 계산한다. `firstShortageDate`, `maximumShortage`, `shortages`와 화면 경고·그래프가 같은 기준을 사용한다.

음수 잔액만 경고하는 기존 방식은 양수 잔액의 운영 자금 부족을 놓친다. 브라우저에만 기준을 저장하는 방식은 기기별로 설정이 달라지고 예측 API와 화면의 경고 기준이 어긋날 수 있어 제외한다.

검증은 기본값 0원의 호환성, 기준액과 같은 잔액, 양수이지만 기준 미달인 잔액을 포함한다.

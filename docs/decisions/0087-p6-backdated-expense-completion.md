# 0087. 일회성 지출의 실제 지출일 선택

상태: 제안

예정일에 지출하고 늦게 기록한 경우, 입력한 날에 차감하면 날짜별 잔액이 실제 흐름과 달라진다.

기존 완료 PUT에 선택 본문 `paidDate`를 추가한다. 한국 시간 시작 잔액 기준일부터 오늘까지 허용한다. 예정일은 보존하고, 과거 날짜는 한국 시간 하루 시작을 기존 `paid_at`에 기록한다. 오늘을 선택하거나 본문을 생략하면 서버 현재 시각을 사용한다. 실제 기록 시각은 `updated_at`에 남기고 재요청은 최초 완료를 유지한다.

예정일을 바꾸는 대안은 원래 일정을 잃는다. 별도 날짜 컬럼은 일 단위 집계에 이미 사용 중인 `paid_at`과 같은 날짜를 중복 관리하므로 제외한다. 정기 지출의 회차 완료 계약은 유지한다.

검증에는 과거 날짜 저장, 기준일 이전·미래 날짜 거절, 예정일과 최초 완료 기록 보존을 포함한다.

# 0081. 정산 주문 상세용 상품 스냅샷 전송

상태: 제안

영업일 D+3 정산과 환불 회수는 픽업 시각을 사용하지 않는다. 주문 상세의 상품명·수량은 계속 보존한다.

기존 HMAC 인증과 PUT /api/v1/order-fulfillments/{orderId}/schedule을 사용하고 상품 목록만 있는 요청을 허용한다. 기존 발신기의 예정 시각과 완료 요청은 전환 기간 동안 받는다. 새 CakeShop 발신기를 켜기 전에 DonWorry 수신부를 배포한다.

새 경로를 동시에 추가하는 대안은 별도 인증 라우팅과 배포 조율이 필요해 이번 전환에서는 제외한다. 기존 데이터를 보존하고 Flyway 변경 없이 적용한다. 정산 상세에서는 픽업 표시를 제거한다. 기존 호출 종료를 확인한 뒤 완료 경로와 남은 저장 코드를 별도로 정리한다.

검증은 상품만 포함한 실제 HMAC 요청의 DB 저장과 매입 연결, 기존 완료 요청 호환을 포함한다.

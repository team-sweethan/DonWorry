# 공통 레이아웃 적용 가이드

실행·시연 계정·검사 명령은 [README](README.md)를 참고합니다.

## 담당 페이지 연결

Case·경보 목록과 상세는 목업 화면에 연결되어 있습니다. 현재 경로별 상태는 [README](README.md#개발)를 봅니다.
거래 내역·사장님 조치 결과·정산 현황은 `EmptyPage`로 연결되어 있으며,
페이지 제목과 옅은 파란 배경·점선 테두리의 **담당자 구현 영역**을 표시합니다.
각 담당자는 본문만 구현합니다. 헤더·사이드바·바깥 여백은 공통 레이아웃이 제공합니다.

1. `src/pages/`의 해당 역할 폴더에 페이지를 만듭니다. 예: `src/pages/security/TransactionsPage.tsx`.

```tsx
import { Card } from 'antd'
import { PageHeader } from '../../components/common/PageHeader'

export function TransactionsPage() {
  return (
    <>
      <PageHeader title="거래 내역" />
      <Card>담당 기능의 본문</Card>
    </>
  )
}
```

2. `src/app/router.tsx`에 페이지를 import하고 해당 경로의 `EmptyPage`를 교체합니다.

```tsx
import { TransactionsPage } from '../pages/security/TransactionsPage'

// /security 경로의 children에서 교체
{ path: 'transactions', element: <TransactionsPage /> }
```

새 경로를 추가하면 `src/config/navigation.ts`의 해당 역할 메뉴에도 같은 URL을 등록합니다.

## 공통 코드 수정 위치

경로는 `src/` 기준입니다.

| 작업               | 위치                                                       |
| ------------------ | ---------------------------------------------------------- |
| 화면 경로 연결     | `app/router.tsx`                                           |
| 메뉴·역할별 홈     | `config/navigation.ts`                                     |
| 헤더·사이드바      | `layouts/AdminLayout.tsx`                                  |
| 색상·간격·공통 CSS | `styles/tokens.ts`, `styles/theme.ts`, `styles/global.css` |
| 페이지 제목        | `components/common/PageHeader.tsx`                         |
| 토스트·확인창      | `components/common/Feedback.tsx`의 `useFeedback()`         |
| 상태 배지          | `components/ui/StatusBadge.tsx`                            |
| HTTP 호출          | `api/` — 기존 `client.ts` 사용                             |

`pages/demo/`에서는 로그인·공통 UI 가이드가 연결되어 있고, 이전 사건·조치 화면은 참고용으로 남아 있습니다.
현재 업무 목업은 `pages/security/`에 있습니다. Case는 `api/cases.ts`·`api/mock/caseMock.ts`,
경보는 `demo/alertMockData.ts`, 시연 로그인·가맹점 선택은 `demo/DemoContext.tsx`에 의존합니다.
실제 인증·API 연동 시 이 시연 의존성을 교체하고 HTTP 호출은 `api/`에 둡니다.
상태 배지를 서버 응답에 연결할 때는 Notion 정본 기준으로 매핑합니다.

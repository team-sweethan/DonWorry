# 부스 안내 — 한 창에서 전체 4~5분

발표 전에 방문자가 돈워리의 사용자와 업무 흐름을 익히는 코스다. 주요 기능을 따라가면서 마스킹·시크릿 키·사후 검토처럼 발표에서 짧게 지나가는 부분도 짚는다. 네모는 줄이지 않고, 설명하는 문장에 맞춰 빠르게 넘긴다.

## 시작 — 이 주소 하나만 열기

**전체 코스:** http://localhost:5173/booth

시작 주소를 열면 **자동 재생·무한 반복**으로 시작한다. 짧은 설명은 4초, 긴 설명은 6~8초 머문다. 관리자 마지막 인사는 7초 유지한 뒤 로그아웃하고 랜딩 첫 박스부터 반복한다. `?autoplay=1`로 명시할 수도 있다.

- **일시정지 / 자동 재생:** 현재 박스에서 멈추거나 다시 진행한다.
- **처음부터:** 랜딩으로 돌아간다. 재생 중이면 다시 재생하고, 일시정지 중이면 멈춘 채 시작한다.
- 이전·다음 수동 조작, 입력, 안내 숨기기, 추가 설명 전환은 자동 재생을 멈춘다.
- 페이지 로딩·계정 전환·강조 대상 준비 중에는 기다린다. 다른 탭으로 이동하면 타이머를 멈추고 이 탭으로 돌아오면 다시 시작한다.
- 자동 로그인에 실패하면 일시정지한다. 오류 상태에서 반복 로그인하지 않는다.
- 수동으로 시작하려면 http://localhost:5173/booth?autoplay=0 을 연다.
- 자동 순회는 기존 읽기 전용 화면 조작만 사용한다. 판정·승인·AI 질문 전송·보고서 생성은 자동 실행하지 않는다. 가린 연락처 조회 감사 기록은 반복할 때마다 추가될 수 있다.

한 창에서 **랜딩·이용 신청·이메일 → 사장님 → 보안 직원 → 관리자** 순서로 진행한다. 다음(→) 또는 PageDown만 누르면 네모와 페이지가 바뀌고, 역할 경계에서는 로그아웃·로그인까지 자동 처리한다. 이전(←)·PageUp으로 돌아갈 때도 필요한 계정으로 전환한다. 기본 코스 합계 4분 30초가 목표이며 실제 소요 시간은 리허설로 확인한다.

기존 시작 주소도 이제 한 창 이어 보기다. `/booth/public`은 랜딩부터 전체 코스를, `/booth/owner`는 사장님부터, `/booth/security`는 보안 직원부터, `/booth/admin`은 관리자부터 이어 본다. 창을 따로 바꿀 필요가 없다.

| 시작 위치               | URL                                                                      | 목표 시간      |
| ----------------------- | ------------------------------------------------------------------------ | -------------- |
| 랜딩부터 전체 코스      | `http://localhost:5173/booth`                                            | 총 4~5분       |
| 기존 소개 주소          | `http://localhost:5173/booth/public`                                     | 소개 40초      |
| 사장님부터 이어 보기    | `http://localhost:5173/booth/owner`                                      | 사장님 65초    |
| 보안 직원부터 이어 보기 | `http://localhost:5173/booth/security?boothCase=411&boothReportCase=411` | 보안 직원 95초 |
| 관리자부터 이어 보기    | `http://localhost:5173/booth/admin`                                      | 관리자 70초    |

계정은 Git에서 제외되는 `boothAccounts.local.ts`를 사용한다. 전체 코스에는 사장님·보안 직원·관리자 계정 세 개를 준비한다. 다른 PC에서는 해당 PC의 실제 계정과 사건 ID로 설정해야 한다. 계정 파일이 들어 있는 프런트 빌드는 배포하지 않는다. 같은 프로필의 다른 탭에서 다른 역할로 로그인하면 이 시연의 세션도 바뀔 수 있으므로 시연 탭 하나로 진행한다.

`H`는 숨기기, `M`은 기본 코스와 추가 설명 전환이다. 시작 주소를 다시 열면 기본 코스로 초기화된다. 입력 칸에서는 방향키를 가로채지 않는다. 네모 설명과 제목을 모두 읽지 않고 아래 대본을 짧게 이어 말한다.

“관리자는 가게와 직원이 서비스를 안전하게 쓰는지 봅니다. 가게 신청을 심사하고, 직원별 사건 배정도 살핍니다. 책상 위 숫자는 맡은 사건 수이고, 새 사건은 적게 맡은 직원에게 자동으로 갑니다. 정지되거나 내부자 조사 중인 직원은 제외합니다. 직원이 전화번호 전체를 본 사유도 사후 검토하며, 관리자에게도 번호 자체는 보이지 않습니다. 직원은 탐지 규칙을 끄자고 요청할 수 있지만 승인 없이 끌 수 없습니다. 사장님 계정의 권한 밖 요청은 거절하고 반복되면 정지합니다. 로그인 공격 중 낯선 브라우저로 들어온 직원 계정도 탈취 의심으로 잡습니다. 직원이 맡지 않은 고객을 계속 조회하면 경보가 올라가고, 높음 상태에서 파일 반출을 시도하면 차단합니다. 발표에서는 이런 일이 실제 결제와 공격 상황에서 어떻게 동작하는지 보여 드립니다.”

## 다음 버튼으로 자동 진행

정산의 상세 목록·지급 내역 탭, 자금 부족 날짜, 가린 연락처 한 건, 전체 연락처 열람 사유 양식, 관리자 직원 책상은 해당 네모에서 자동으로 열린다. 연락처 양식은 다음 네모로 넘어갈 때 자동으로 닫는다. 조회 데이터가 오는 동안 다음 버튼은 잠깐 기다린다.

자동 조작은 `boothPreparation.ts`에 등록된 읽기 전용 컨트롤만 사용한다. 가린 연락처 조회도 실제 감사 기록을 남긴다. 원문 번호 요청·판정·승인·키 발급·AI 생성·질문 전송·계정 변경은 시연 진행에서 실행하지 않는다. 이미 저장된 보고서를 읽는다.

- 직원 시작 주소: `/booth/security?boothCase=411&boothReportCase=411`. 기존 브라우저의 사건 설정도 이 주소로 교체한다.
- 접힌 키 이력·계산 근거는 자동으로 펼친다.
- 로그인 보안은 현재 상태를 그대로 보여 준다. 실제 공격과 계정 정지는 발표 시연으로 연결한다.
- `화면 준비 확인`이 계속되면 서버·로그인·실제 데이터 상태를 확인한다.

## 추가 설명

`M`으로 전환하면 전체 거래 목록·차단 목록·ML 참고 점수·사건 비교·직원 계정 관리 등도 볼 수 있다. 기본 코스의 4~5분 목표에는 이 추가 화면을 포함하지 않는다. 배포 서버의 실제 결제·공격 시연과 로컬 부스 안내는 따로 준비한다.

날짜가 바뀌면 예정 정산·부족 날짜가 과거로 넘어갈 수 있으므로 리허설 때 표시 날짜를 확인한다. 기본 코스 전체 소요 시간은 아직 측정하지 않았다.

## 다른 PC에서 브랜치 확인하기

이 브랜치는 공유용으로 push하되 `dev`·`main`에는 머지하지 않는다.

```bash
git fetch origin
git switch --track origin/local/booth-tour
cd frontend
npm ci
cp src/booth/boothAccounts.example.ts src/booth/boothAccounts.local.ts
npm run dev
```

이미 로컬 브랜치가 있으면 `git switch local/booth-tour` 후 `git pull --ff-only`로 갱신한다.

`boothAccounts.local.ts`에 **본인 로컬 DB에 존재하는 기존 계정**의 아이디·비밀번호와 담당 사건·보고서·평가 ID를 넣는다. 계정 파일은 Git에서 제외되며 예제의 빈 비밀번호로는 자동 로그인하지 않는다. 시작 URL은 이 문서의 표를 따른다. 담당 사건 ID를 바꿨다면 브라우저의 `boothCase`·`boothReportCase` 주소 설정도 바꾼다.

백엔드·DB도 각 PC에서 별도로 실행해야 한다. 이번 PC에 추가한 DB 레코드, `application-local.yml`, 암호화 키, 계정 파일과 Desktop 폴더의 문서는 push에 포함되지 않는다. 사건 411·평가 30079 같은 숫자는 이번 PC의 예시이며 다른 DB에 그대로 적용할 수 없다. 계정 파일이 없는 경우 소개 코스만 볼 수 있다.

## 한 창 이어 보기 확인 — 2026-11-17

`/booth`와 `/booth/public`에서 시작해 다음 버튼으로 역할과 페이지를 이어 간다. 기존 역할별 시작 URL도 그 역할부터 나머지 코스를 이어 보도록 바꿨다. 실제 브라우저에서 사장님·보안 직원·관리자 자동 계정 전환과 관리자 마무리 26/26까지 확인했다. 원문 연락처 양식에서는 다음 방향키로 자동 닫힘도 확인했다. 유료 AI 요청·판정·승인·계정 상태 변경은 실행하지 않았다.
